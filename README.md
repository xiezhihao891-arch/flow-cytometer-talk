# 流式细胞仪：从细胞计数到单细胞分析

中山大学课程「实验安全与生物安全」汇报用离线演示（约 8 分钟 + 提问）。

本文件为教学演示，不代表学校官方发布，不含校徽或正式印章。

## 如何打开

用现代浏览器直接打开 `index.html` 即可，无需网络、无需安装。建议全屏（按 `F`）以 16:9 投影。

也可在本目录启动本地服务，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 快捷键

- `→` / 空格 / `PageDown`：下一页
- `←` / `PageUp`：上一页
- `Home` / `End`：封面 / 末页
- `1`–`9`、`0`、`-`：跳到对应页
- `F`：全屏
- `H`：演讲提示
- `Esc`：总览
- `?`：快捷键说明

第 6 页为可操作的流式细胞仪教学模拟器（示意性模型，非真实仪器规格）。可用「演示脚本」自动走一遍正常采集、聚焦失败、激光关闭与安全联锁。
